## 复核步骤

1. 首页只有导入 PRD 是当前步骤，其余显示依赖顺序。
2. 上传 PRD 后模型先分析和提问；回答完成后查看需求确认单。
3. 勾选确认需求后才出现技术文档；修改文档需重新确认。
4. 确认文档进入书签步骤；保存成功后才显示开发入口。
5. 开发结束检查结果与证据，验收后进入下一轮文档，重新走确认和书签。
6. 「项目记录」按轮次回看技术文档、确认与代码快照。

真实使用第 2 步起会调用用户配置的本机 Codex。交付联调使用独立数据目录和明确标注的固定测试执行器；其输出不代表真实模型能力。

## 多项目与可恢复归档

- 入口分工：搭建流程展示当前选中的软件；项目记录管理未归档项目；项目归档置于最近项目下方。
- 两份隔离测试 PRD 分别停在「确认需求」和「模型提问」，相互切换后进度保留。
- 查看甲项目记录后点击搭建流程，仍返回当前的乙项目；明确点击「继续开发」才改变当前项目。
- 归档当前项目后，它从最近项目和项目记录移除，归档页保留原步骤和需求问答；刷新归档页后仍在。
- 恢复后返回项目记录，继续开发进入原来的确认需求步骤；刷新首页仍记住所选项目。
- 手机 390×844 检查列表、菜单、归档和恢复；页面宽度与滚动宽度均为 390，无横向溢出。最近项目旁加号为 0 个。
